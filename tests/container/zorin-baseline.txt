# Packages the container image adds to ubuntu:24.04 so it starts where a fresh Zorin OS 18 install does, as far as
# the non-GUI modules are concerned. Every name below except `git` is in Zorin's own install manifest
# (/var/log/installer/initial-status.gz on a Zorin OS 18.1 install, 1976 packages), i.e. it ships with Zorin.
# The full desktop set is left out on purpose (GNOME, apps, firmware, flatpak, snapd: the GUI modules are not run
# in the container), so this is a subset of a fresh Zorin, never a superset.
#
# Delta vs a fresh Zorin install:
#   + git          NOT preinstalled on Zorin 18; the README quick start installs it (step 1) to clone this repo.
#   - snapd, flatpak and the desktop  not installed (no daemons in the container; the steps that need them are
#                  skipped explicitly, see tests/generated/container-skips.tsv).
#   ~ systemd      installed (timedatectl/systemctl exist, as on Zorin) but not running as PID 1.
#   ~ the image is Ubuntu's "minimized" cloud image (no man pages or /usr/share/doc beyond copyright files).
#
# One package per line; `#` starts a comment.
