# Packages the container image adds to ubuntu:26.04 so it starts where a fresh Ubuntu 26.04 LTS desktop install
# does, as far as the non-GUI modules are concerned. Every name below except `git` and `curl` is in the Ubuntu
# 26.04 desktop image (the package list the image build installs, the first entries of /var/log/apt/history.log
# on a fresh 26.04.1 install), i.e. it ships with Ubuntu Desktop.
# The full desktop set is left out on purpose (GNOME, apps, firmware, snapd: the GUI modules are not run in the
# container), so this is a subset of a fresh Ubuntu Desktop, never a superset.
#
# Delta vs a fresh Ubuntu 26.04 desktop install:
#   + git, curl    NOT preinstalled on Ubuntu 26.04 Desktop; the README quick start installs them (step 1).
#   - snapd and the desktop  not installed (no daemons in the container; the steps that need them are
#                  skipped explicitly, see tests/generated/container-skips.tsv). flatpak is not preinstalled on
#                  Ubuntu either; 60-desktop-apps installs it.
#   ~ systemd      installed (timedatectl/systemctl exist, as on Ubuntu) but not running as PID 1.
#   ~ the image is Ubuntu's "minimized" cloud image (no man pages or /usr/share/doc beyond copyright files).
#
# One package per line; `#` starts a comment.
